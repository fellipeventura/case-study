# Estudos de Caso DBA

Repositório para documentação de estudos de caso relacionados a PostgreSQL, SQL Server, performance, manutenção, backup, autovacuum, logs, migrações e rotinas operacionais.

## Estrutura

- estudos de caso relacionados a PostgreSQL
- estudos de caso relacionados a SQL Server
- imagens/: imagens sanitizadas utilizadas nos documentos

## Boas práticas

- Não armazenar senhas, tokens, IPs sensíveis ou strings de conexão reais.
- Não publicar nomes internos de servidores, bases ou usuários sem sanitização.
- Remover dados de clientes, cooperados, usuários e ambientes produtivos.
- Preferir exemplos anonimizados e métricas agregadas.
